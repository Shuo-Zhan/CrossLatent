# GitHub upload contents

Repository: https://github.com/Shuo-Zhan/CrossLatent.

Upload the contents of `CrossLatent/` to the repository root. It contains software 0.1.4, documentation, original analysis implementations, 100 final prediction models and all 1,000 fitted-budget models. Plotting scripts and rendered figures are omitted.

Study data and RNA SAE parameters are distributed through the verified Google Drive links in the README and [download guide](DOWNLOADS.md). Their SHA256 values are in [DATA_SHA256SUMS.txt](DATA_SHA256SUMS.txt). Keep those ZIPs and model weights outside Git history. The RNA archive omits SAE training/development FASTAs.

Software citation metadata are supplied in CITATION.cff. An actual preprint or publication link can be added when available. The associated article title does not imply a publication DOI or acceptance status.

Preserve unrelated existing remote changes when uploading. Preparing local code files does not upload them to GitHub or create a remote release tag or archival DOI. Retain author-selected software licensing and upstream attribution; data and weights retain their source conditions.
