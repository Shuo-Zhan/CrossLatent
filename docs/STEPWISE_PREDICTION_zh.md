# CrossLatent 分步预测输出

CrossLatent 通过通用 API 和命令行接口提供文章 Fig4 中的分步预测，可追踪每个 SAE 特征对各序列位置预测分数的贡献。

## 分步预测如何计算

按最终模型保存的特征选择顺序，逐项加入特征贡献：

```text
第 s 步的位置分数 = 最终截距 + 前 s 个特征的「最终系数 × 该位置激活」之和
```

每一步使用同一组最终系数、截距和冻结阈值，不重新拟合、不重新选择阈值。最后一步的分数及标签与原来的最终预测一致。这里的分数是原始线性分数，不是概率。

第 0 步仅包含截距，作为变化比较的起点；第 1 到 K 步依次增加一个特征。二元任务使用 `分数 >= 冻结阈值` 得到候选标签。

`model.json` 中的 `metadata.validation_path` 记录的是各个预算分别拟合后的模型及验证结果。本次输出对应的是 Fig4 使用最终模型系数逐项累积的轨迹，两者分别保留。最终模型包含 K 个特征时，输出 K 个特征步骤；训练时考察的全部预设预算仍在训练历史中。

## 命令行使用

```sh
crosslatent predict-steps \
  --model model.json \
  --activations activations.npy \
  --dictionary-id 实际使用的字典标识 \
  --lengths lengths.npy \
  --sequence-ids sequence_ids.json \
  --output trajectory_output
```

- `activations.npy`：位置数 × 完整字典特征数，列顺序须与冻结模型对应。提前去除特殊 token 和 padding。
- `lengths.npy`：每条序列的有效长度，须为正整数，合计等于位置数。省略时将全部位置视为一条序列。
- `sequence_ids.json`：唯一且非空的序列标识列表，可省略，由程序生成编号。
- `dictionary-id`：实际编码所使用的字典标识，必须与模型一致。
- `output`：新的输出文件夹，避免覆盖已有轨迹。

## Python 接口

```python
from crosslatent import LinearReadout, predict_steps, export_steps
import numpy as np

model = LinearReadout.load('model.json')
activations = np.load('activations.npy', mmap_mode='r')
lengths = np.load('lengths.npy')

trajectory = predict_steps(
    model, activations,
    dictionary_id=model.dictionary_id,
    lengths=lengths,
)

export_steps(
    model, activations, 'trajectory_output',
    dictionary_id=model.dictionary_id,
    lengths=lengths,
)
```

字典标识须来自实际使用的编码协议，不能将另一套字典的激活重新标为当前模型字典。轨迹会保留位置 × 步骤的数组；大型数据集可按若干条序列分批导出。

## 输出内容

| 文件 | 内容 |
|---|---|
| `positions.csv` | 每条序列、每个位置、每一步的分数、候选标签、新加入特征 ID、系数、激活、带符号贡献，以及标签变化 |
| `steps.csv` | 每条序列各步新增特征及正标签、保留、新增、移除的数量 |
| `trajectory.npz` | 完整精度的位置分数、激活、贡献、候选标签、变化数组，以及特征顺序、序列边界和字典标识 |
| `model.json` | 本次导出使用的冻结模型 |
| `metadata.json` | 轨迹模式、冻结阈值、步骤与坐标约定 |
| `README.md` | 本次输出的说明 |

位置编号从 1 开始，在每条序列内重新计数。分数和标签数组包含第 0 步，共 K+1 列；激活、贡献和变化数组对应第 1 到 K 步，共 K 列。

## 标签变化如何解释

变化相对于实际前一步计算：

- **保留**：前一步和当前步骤均为正标签。
- **新增**：前一步为负，当前步骤为正。
- **移除**：前一步为正，当前步骤为负。
- **negative**：两步均为负标签。

第 1 步与仅含截距的第 0 步比较。因此，如果截距本身超过阈值，第 1 步也可能出现保留或移除。这里记录的是预测变化；是否正确，需要另行对照真实注释或生物学证据。

RNA、蛋白质二元任务输出候选标签与变化；DNA 连续任务输出各步分数、特征激活及贡献，二元标签和变化字段留空。

## 如何支持审阅和选步

使用者可以比较各步候选，定位标签发生变化的边界或位置，查看是哪一个特征、以怎样的贡献促成了变化，再结合序列或结构证据选择步骤或修订局部标签。这对应文章提出的核心能力：将最终标签展开为有分数、特征来源和位置变化的多步候选，为选择与修订提供依据。

程序输出可供审阅的候选和来源，不自动执行专家纠正，也不依据测试标签选择步骤。导出过程不需要重新训练或运行基础序列模型。

## 输出示例

以下为接口验证用的人工构造例子，不是论文实验数据。固定截距为 0、阈值为 0.5，第 1 步加入特征 2（系数 +1），第 2 步加入特征 0（系数 −1）。

| 位置 | 步骤 | 新加入特征 | 该特征贡献 | 累积分数 | 候选标签 | 变化 |
|---|---|---|---|---|---|---|
| 1 | 1 | 2 | +1 | 1 | 1 | 新增 |
| 1 | 2 | 0 | 0 | 1 | 1 | 保留 |
| 2 | 1 | 2 | +1 | 1 | 1 | 新增 |
| 2 | 2 | 0 | −1 | 0 | 0 | 移除 |

位置 2 的标签由正变负，可以追溯到第 2 步加入的特征 0 及其 −1 贡献。真实应用中，使用者可进一步检查该特征的响应上下文，并依据生物学证据判断是否保留这次变化。
